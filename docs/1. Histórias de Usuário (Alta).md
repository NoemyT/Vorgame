# Vorgame — Histórias de Usuário (Prioridade Alta)

## Recorte do protótipo desta entrega

O protótipo incluirá **HU01 a HU05 como obrigatórias (must have)**. A **HU06 fica para uma entrega posterior**, assim como a exibição de reviews prevista originalmente na HU04. A prioridade alta representa o produto planejado; ela não significa que todas as seis histórias serão implementadas nesta entrega.

| História | Escopo nesta entrega |
| --- | --- |
| HU01 — Criar conta | Obrigatória |
| HU02 — Fazer login | Obrigatória |
| HU03 — Pesquisar jogos | Obrigatória |
| HU04 — Visualizar detalhes de um jogo | Obrigatória, sem exibição de reviews |
| HU05 — Avaliar jogo | Obrigatória |
| HU06 — Publicar review | Adiada, incluindo edição e exclusão |

O fluxo de demonstração será: criar conta, fazer login, pesquisar um jogo, abrir seus detalhes, atribuir uma nota e alterar essa nota, conferindo a média atualizada. A busca e a consulta de detalhes também estarão disponíveis sem login; avaliar exige autenticação.

A busca usa a IGDB v4. O Vorgame guarda os dados dos jogos retornados no MySQL via Prisma e atribui um ID local para os detalhes e as avaliações. Os jogos fictícios da carga inicial continuam acessíveis pelos links existentes. A interface administrativa de catálogo segue fora do protótipo. A decisão original e sua evolução estão registradas nos [ADRs](2.%20ADR.md).

O protótipo estará pronto quando os critérios das cinco histórias incluídas forem atendidos de ponta a ponta, com persistência no banco e validação das regras de acesso e avaliação. Reviews, perfil público do autor, comentários, notificações e recomendações ficam fora desse aceite. As caixas abaixo são a lista de verificação para o aceite.

---

## HU01 — Criar conta

**Entrega:** obrigatória no protótipo.

Como visitante, quero criar uma conta para acessar os recursos da plataforma.

**Critérios de aceitação:**

- [ ] Informar nome, e-mail, nome de usuário e senha.
- [ ] E-mail e nome de usuário devem ser únicos.
- [ ] Campos obrigatórios não podem ficar vazios.
- [ ] Ao concluir o cadastro, a conta deve ser criada com sucesso.

---

## HU02 — Fazer login

**Entrega:** obrigatória no protótipo.

Como usuário cadastrado, quero fazer login para acessar minha conta.

**Critérios de aceitação:**

- [ ] Informar e-mail ou nome de usuário e senha.
- [ ] Credenciais inválidas devem exibir mensagem de erro.
- [ ] Credenciais válidas devem iniciar a sessão.
- [ ] Usuário autenticado deve acessar recursos restritos.

---

## HU03 — Pesquisar jogos

**Entrega:** obrigatória no protótipo; consulta pública.

Como usuário, quero pesquisar jogos para encontrar rapidamente títulos de interesse.

**Critérios de aceitação:**

- [ ] Pesquisar jogos na IGDB por trecho do título, sem distinguir maiúsculas de minúsculas.
- [ ] Exibir os resultados e identificar a fonte com o crédito **Dados de jogos: IGDB**.
- [ ] Exibir carregamento, lista vazia para uma busca concluída sem jogos e erro com opção de tentar novamente quando a fonte estiver indisponível.
- [ ] Abrir a página de detalhes pelo ID local retornado na busca. Uma nova busca pelo mesmo jogo deve reutilizar esse ID.

---

## HU04 — Visualizar detalhes de um jogo

**Entrega:** obrigatória no protótipo, com exibição de reviews adiada.

Como usuário, quero visualizar a página de um jogo para consultar suas informações e avaliações.

**Critérios de aceitação do protótipo:**

- [ ] Exibir título, capa, descrição, gênero e plataformas, com indicação para metadados ausentes ou capa indisponível.
- [ ] Exibir a nota média da comunidade do Vorgame e distinguir jogos ainda sem avaliações.
- [ ] Exibir a própria nota ao usuário autenticado ou indicar que ele ainda não avaliou o jogo. A criação e a alteração da nota estão disponíveis na API.
- [ ] Permitir abrir os detalhes sem login pelo ID local, inclusive quando a IGDB estiver indisponível.

**Critério adiado para a entrega da HU06:**

- [ ] Exibir reviews publicadas por usuários.

---

## HU05 — Avaliar jogo

**Entrega:** obrigatória no protótipo.

Como usuário autenticado, quero atribuir uma nota a um jogo para registrar minha opinião.

**Critérios de aceitação:**

- [ ] Apenas usuários autenticados podem avaliar.
- [ ] A nota deve estar entre 0 e 10.
- [ ] Cada usuário pode manter apenas uma avaliação por jogo.
- [ ] Vincular a nota ao mesmo ID local usado na busca e nos detalhes. Repetir a busca deve preservar a nota e os agregados.
- [ ] O usuário pode alterar sua nota posteriormente.
- [ ] A média do jogo deve ser atualizada após a avaliação.

O [roteiro no Swagger](../backend/README.md#roteiro-de-aceite-com-terraria) cobre criação, consulta e alteração da nota no mesmo jogo.

---

## HU06 — Publicar review

**Entrega:** adiada; não integra o aceite do protótipo atual.

Como usuário autenticado, quero escrever uma review sobre um jogo para compartilhar minha opinião.

**Critérios de aceitação:**

- [ ] Apenas usuários autenticados podem publicar.
- [ ] A review deve estar vinculada a um jogo.
- [ ] O texto não pode estar vazio.
- [ ] A review deve aparecer na página do jogo e no perfil do autor.
- [ ] O autor pode editar ou excluir sua própria review.
